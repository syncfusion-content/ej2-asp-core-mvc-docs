The DropdownTree component can be localized for any culture by configuring its text and messages according to the target culture. The default locale of the DropdownTree is `en` (English). The following table represents the default texts and messages of the DropdownTree in `en` culture.

|----|----|
|noRecordsTemplate|No records found|
|actionFailureTemplate|Request failed|
|overflowCountTemplate|+${count} more...|
